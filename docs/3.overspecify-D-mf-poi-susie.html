The previous page fits MF-Poisson-SuSiE with the correct value \(D = 3\). This page stress-tests the same model with \(D = 5\), while the data-generating mechanism still has at most three active factors per observation.

The question is whether the two extra single-effect dimensions become harmless. A benign extra dimension should either have small posterior expected loading mass, diffuse posterior assignment probabilities \(\bar\gamma_{idk}\), or both. This makes overfitted \(D\) a data-wise diagnostic: for each observation \(i\), we inspect the fitted dimensions \(d=1,\ldots,D\) and ask which dimensions carry real loading mass.

Diagnostics

When D is overspecified, raw assignment probabilities can be misleading: every fitted effect must choose a factor. We therefore score support recovery using posterior expected loading mass, \[ \sum_d q(\gamma_{id} = k) E_q[\beta_{id} \mid \gamma_{id}=k], \] so that extra effects with small posterior size have little influence.

row_cosine = function(A, B) {
  A_norm = sqrt(rowSums(A^2))
  B_norm = sqrt(rowSums(B^2))
  (A %*% t(B)) / (A_norm %o% B_norm)
}

all_permutations = function(x) {
  if (length(x) == 1) return(matrix(x, nrow = 1))
  do.call(rbind, lapply(seq_along(x), function(i) {
    cbind(x[i], all_permutations(x[-i]))
  }))
}

match_factor_rows = function(F_hat, F_true) {
  K = nrow(F_true)
  similarity = row_cosine(F_hat, F_true)
  perms = all_permutations(seq_len(K))
  scores = apply(perms, 1, function(p) {
    sum(similarity[cbind(seq_len(K), p)])
  })
  learned_to_true = perms[which.max(scores), ]

  data.frame(
    learned_factor = seq_len(K),
    matched_true_factor = learned_to_true,
    cosine = similarity[cbind(seq_len(K), learned_to_true)]
  )
}

loading_scores = function(fit) {
  E_beta = fit$alpha / fit$lambda
  apply(fit$gamma_bar * E_beta, c(1, 3), sum)
}

effect_sizes = function(fit) {
  E_beta = fit$alpha / fit$lambda
  rowSums(fit$gamma_bar * E_beta, dims = 2)
}

effect_gamma_entropy = function(fit) {
  entropy = -fit$gamma_bar * log(fit$gamma_bar)
  entropy[is.nan(entropy)] = 0
  rowSums(entropy, dims = 2) / log(dim(fit$gamma_bar)[3])
}

effect_max_gamma = function(fit) {
  apply(fit$gamma_bar, c(1, 2), max)
}

effect_top_factor = function(fit) {
  apply(fit$gamma_bar, c(1, 2), which.max)
}

rank_by_effect_size = function(effect_mat, size_mat) {
  out = matrix(0, nrow = nrow(effect_mat), ncol = ncol(effect_mat))
  for (i in seq_len(nrow(effect_mat))) {
    ord = order(size_mat[i, ], decreasing = TRUE)
    out[i, ] = effect_mat[i, ord]
  }
  out
}

rank_gamma_bar_by_size = function(fit, size_mat) {
  N = dim(fit$gamma_bar)[1]
  D = dim(fit$gamma_bar)[2]
  K = dim(fit$gamma_bar)[3]
  out = array(0, dim = c(N, D, K))
  for (i in seq_len(N)) {
    ord = order(size_mat[i, ], decreasing = TRUE)
    out[i, , ] = fit$gamma_bar[i, ord, ]
  }
  out
}

map_scores_to_true = function(scores, learned_to_true) {
  K = length(learned_to_true)
  out = matrix(0, nrow = nrow(scores), ncol = K)
  for (k in seq_len(K)) {
    out[, learned_to_true[k]] = out[, learned_to_true[k]] + scores[, k]
  }
  out
}

support_labels_from_scores = function(scores, support_sizes) {
  vapply(seq_len(nrow(scores)), function(i) {
    active = order(scores[i, ], decreasing = TRUE)[seq_len(support_sizes[i])]
    paste(sort(active), collapse = ",")
  }, character(1))
}

normalized_entropy = function(scores) {
  prob = scores / rowSums(scores)
  entropy = -prob * log(prob)
  entropy[is.nan(entropy)] = 0
  mean(rowSums(entropy)) / log(ncol(scores))
}

extra_effect_mass_fraction = function(fit, true_support_size) {
  sizes = effect_sizes(fit)
  vapply(seq_len(nrow(sizes)), function(i) {
    sorted_sizes = sort(sizes[i, ], decreasing = TRUE)
    extra_idx = seq.int(true_support_size[i] + 1, length(sorted_sizes))
    sum(sorted_sizes[extra_idx]) / sum(sorted_sizes)
  }, numeric(1))
}

Interpreting Overfitted D

For fixed learned F, gamma_bar[i, d, k] quantifies posterior uncertainty in which factor receives effect d for observation i. When D is overspecified, there are more effects than the true loading support needs. A well-behaved fit can handle this in two ways: extra effects can have small expected size, or they can remain diffuse in gamma_bar so that no factor receives strong posterior support from them.

The most useful summaries here are therefore effect size and entropy together. Expected effect size, \[ E_q[\beta_{id}] = \sum_k \bar\gamma_{idk} E_q[\beta_{id} \mid \gamma_{id}=k], \] measures whether effect d carries meaningful loading mass. Normalized entropy of gamma_bar[i, d, ] measures whether the factor identity of that effect is resolved. Extra dimensions are benign when they have low expected size, high assignment entropy, or both. They are problematic when they have sizable expected loading mass and low entropy, because then the overfitted dimension is acting like an additional confident component rather than an uncertain residual effect.
